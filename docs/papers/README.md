# TCN Paper Archive

Local copies of the TCN papers used to audit and implement the NEMBA temporal
convolutional backbone variants. PDFs were downloaded from arXiv on
2026-06-23. The Emergent Mind review is a web resource, so it is linked rather
than mirrored here.

Review source: [Emergent Mind, Temporal Convolutional Networks](https://www.emergentmind.com/topics/temporal-convolutional-networks)
